# 桌面端模型与强度选择器实验

本分支从 `b5d6cdc` 建立。目标是在 agy-capsule 的同一张面板里点选某个模型的某个档位，让当前会话一次完成切换。实验开关默认关闭。开启入口在插件侧栏的设置页，名称为「模型与强度选择器（实验）」。

## 源码依据

现有的窄栏布局会给原生控件加压缩样式，Turbo 按钮已有压成图标的先例。原先的模型压缩逻辑按位置和文本选择一组元素，适合分配宽度。实验单独定位当前可见输入框里的模型按钮，只调整这个按钮的外观。

参考项目从这个按钮读取 React 组件树中的模型选项和会话上下文。它把模型及其档位表示为一个完整的宿主选项，并用一次会话 setter 调用提交。作者记录的桌面验证版本为 2.32.1。这是私有界面，在其他版本上的组件形状、写入和持久化语义都需要实测。[参考实现](https://github.com/LLYSH-HANNARI/antigravity-Codex-Claude-effort-slider/blob/c45c3fccaba43d238bce22d5023d7233e4be5ec1/lib/client.js#L1944) · [作者记录](https://github.com/LLYSH-HANNARI/antigravity-Codex-Claude-effort-slider/blob/c45c3fccaba43d238bce22d5023d7233e4be5ec1/README.md)

## 分支实现

- 开启功能后，只有在读到当前会话标识、可选项、已选项和会话读写方法时，才挂载面板并将原生按钮缩成可点击的「⋯」。尚未建立会话或接口不匹配时使用原生入口。
- 选项来自当前宿主。已知档位后缀按模型分行，其余标签完整显示。写入使用宿主给出的原始标签。提交前重新识别输入框、会话和有效选项，提交后以会话回读为准。三秒内未确认会显示提示。
- 本实验给会话 setter 的第三个参数传 `false`，意图将操作限于当前会话。参考项目使用 `true` 并在注释中提到全局默认值。两个取值的实际影响还需与同版本的原生操作对照。关闭设置或卸载会清理插件创建的控件和小泡样式。
- 实现复用 agy-capsule 的 CDP 渲染器。没有引入第三方安装补丁，也没有新增网络请求或选项日志。

## 本地 Gemini 审查与验证

从本分支按仓库现有的本地安装或更新流程加载插件。先在一个已有对话中启用功能。审查时优先看 `agy-capsule/sidecars/agy_capsule/model_picker.mjs`，再看 `deck_injector.mjs` 中的挂载、清理和窄栏逻辑。

| 场景 | 应观察的结果 |
| --- | --- |
| 保留草稿，从另一个模型点选目标模型的 High | 原生菜单重开后同时选中目标模型和 High，草稿完整。若能在本机读取下一次正常请求的模型元数据，可另行核对；仅看插件标签无法确认请求实际路由。 |
| 有两个已有对话，或面板打开时切到另一个对话 | 一个对话的选项不会提交到另一个会话。没有会话标识的新对话仍能打开原生菜单。 |
| 核对持久化 | 对比原生菜单和自定义面板分别切换后，当前会话、另一个已有会话、随后新建会话各自的模型与档位。记录客户端版本和结果即可。 |
| 缩窄窗口、点原生小泡、关闭实验开关 | 小泡可打开原生菜单，其他底栏按钮仍可操作，关闭开关后原生按钮恢复。 |
| 检查宿主兼容性 | 核对各行档位与原生菜单一致，包括固定模型、不可用选项。若开启后没有自定义入口，先核对按钮、候选列表及会话 getter 的实际形状。 |

## 已执行的测试

运行 `node --test test/*.test.mjs`，77 项通过，3 项 Windows 专用测试在 Linux 跳过。新增单元测试覆盖跨模型的单次提交、未确认时保持宿主回读值、React 切换组件树以及缺少会话上下文。测试数据均为虚构。

新增的 Playwright 场景覆盖开关、22 像素小泡、跨模型点选、草稿保留与过期会话。当前执行环境禁止 Chromium 创建启动所需的本地套接字，浏览器断言尚未执行。可按仓库说明运行 `node test/browser-regressions.mjs`。模拟组件树无法验证 Antigravity 的真实状态持久化，本分支尚待 Windows 桌面验收。
